PLP Python Week 4

This repository contains my solutions for the PLP Python Week 4 assignment.

welcome.py - Defines a welcome() function that creates personalized PLP welcome messages.

toolbox.py - Defines double(), is_pass(), and greet() functions and tests each one.

The greet() function was the hardest to write because it uses a default parameter while also allowing a different greeting to be provided. Understanding how the default value works helped me see how functions can be made more flexible.
